# 📊 UPI Transactions Analysis Dashboard | Power BI

## 📌 Project Overview

The **UPI Transactions Analysis Dashboard** is an interactive Power BI project designed to analyze digital payment transactions and uncover meaningful business insights. The dashboard helps understand transaction trends, user behavior, payment methods, bank performance, and fraud patterns using visual analytics.

This project demonstrates data cleaning, data transformation, DAX calculations, and dashboard development skills commonly required for Data Analyst roles.

---

## 🎯 Objectives

- Analyze overall UPI transaction performance.
- Monitor transaction amount and transaction count.
- Identify peak transaction hours.
- Compare sender and receiver banks.
- Analyze payment methods used by customers.
- Understand spending patterns across different age groups.
- Detect fraudulent transactions.
- Build an interactive dashboard for business decision-making.

# 📊 Business Insights

### 💳 Transaction Trends

- Total transaction volume shows steady digital payment adoption.
- Most transactions occur during evening hours.
- Successful transactions significantly outnumber failed transactions.

---

### 🏦 Bank Performance

- Certain banks process the highest number of transactions.
- Top sender and receiver banks contribute the majority of payment volume.

---

### 👥 Customer Insights

- Users aged **25–35 years** contribute the highest transaction amount.
- Young adults perform more frequent UPI transactions compared to other age groups.

---

### 💰 Payment Methods

- UPI remains the most preferred digital payment method.
- Wallet and card-based transactions account for a smaller share.

---

### 🚨 Fraud Analysis

- Fraudulent transactions represent only a small percentage of total transactions.
- Fraud monitoring can help improve payment security.
